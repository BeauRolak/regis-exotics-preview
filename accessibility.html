Accessibility

This site is built to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA.

What is in place

  • Every page works with a keyboard, with a visible focus outline and a link to skip to the content.
  • Photos have text descriptions. Video clips are silent, never start with sound, and each has a written description beside it.
  • The home page video can be paused, and does not play for visitors who ask their device to reduce motion. Cursor effects and page transitions are switched off for them too.
  • The walkaround view has a slider that works with arrow keys, and the same vehicle can always be seen in still photos.
  • Forms have labelled fields and say in plain words what went wrong.

What has been checked

Each page was scanned with an automated accessibility checker and used by keyboard in a desktop browser. It has not yet been tested with screen readers on phones.

Tell us about a problem

If something on this site is hard to use, message @regisexotics on Instagram and say which page it was on.
